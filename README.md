# Tasty Table — ონლაინ რესტორნის აპლიკაცია (Django)

პროექტი შედგება ორი გვერდისგან:
1. **მენიუს გვერდი** (`/`) — კერძების დათვალიერება და ფილტრაცია კატეგორიის, სიცხარის დონის (0–4), ნიგვზიანობისა და ვეგეტარიანულობის მიხედვით. თითოეულ ბარათზე ჩანს სურათი, დასახელება, სიცხარის მაჩვენებელი, ნიგვზიანობა/ვეგეტარიანულობა, ფასი და „კალათაში დამატების" ღილაკი.
2. **კალათის გვერდი** (`/cart/`) — შეკვეთილი კერძების სია, რაოდენობის ცვლილება, წაშლა და ჯამური თანხის დინამიური გამოთვლა.

კალათა ინახება მომხმარებლის სესიაში (session), ასე რომ ავტორიზაცია არ არის საჭირო.

## პროექტის სტრუქტურა

```
restaurant_project/
├── manage.py
├── requirements.txt
├── restaurant/          # პროექტის settings, urls
└── menu/                # აპლიკაცია: მოდელები, ვიუები, ტემფლეითები
    ├── models.py         # Dish მოდელი
    ├── views.py          # dish_list, cart_detail, add_to_cart, update_cart_item
    ├── cart.py           # სესია-ზე დაფუძნებული Cart კლასი
    ├── urls.py
    ├── admin.py
    ├── management/commands/seed_dishes.py   # sample მონაცემების ჩატვირთვა
    ├── templates/menu/   # base.html, dish_list.html, cart.html
    └── static/menu/css/style.css
```

## გაშვება

1. შექმენით ვირტუალური გარემო და დააინსტალირეთ დამოკიდებულებები:

```bash
python -m venv venv
source venv/bin/activate        # Windows-ზე: venv\Scripts\activate
pip install -r requirements.txt
```

2. გაუშვით მიგრაციები (ცხრილების შექმნა):

```bash
python manage.py migrate
```

3. (არასავალდებულო, მაგრამ რეკომენდებულია) ჩატვირთეთ სატესტო კერძები, რომ მენიუ ცარიელი არ იყოს:

```bash
python manage.py seed_dishes
```

4. შექმენით ადმინისტრატორის ანგარიში — რომ /admin/-დან დაამატოთ კერძების სურათები და ახალი პოზიციები:

```bash
python manage.py createsuperuser
```

5. გაუშვით სერვერი:

```bash
python manage.py runserver
```

გახსენით ბრაუზერში:
- მენიუ: `http://127.0.0.1:8000/`
- კალათა: `http://127.0.0.1:8000/cart/`
- ადმინ პანელი (სურათების ასატვირთად): `http://127.0.0.1:8000/admin/`

## შენიშვნა სურათებზე

`seed_dishes` ბრძანება ამატებს კერძებს სურათების გარეშე (ბარათებზე გამოჩნდება პლეისჰოლდერი 🍲). სურათების დასამატებლად შედით `/admin/`-ში, აირჩიეთ კერძი და ატვირთეთ სურათი `image` ველში.
